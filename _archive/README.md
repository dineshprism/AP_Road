# Archive

Legacy, one-off, and development-only files moved here to keep the repository root clean.

**Do not import from `_archive/` in production code.** Active application code lives in `src/`, `server/src/`, `public/`, and `data/`.

| Subfolder | Contents |
|-----------|----------|
| `docs/` | Superseded root-level markdown guides and status notes |
| `dev-tests/` | Standalone HTML/JS test pages and scripts |
| `logs/` | Local dev log files |
| `reports/` | Audit and security scan exports |
| `data-exports/` | Duplicate spreadsheets, hierarchy JSON drafts, extra CSV exports |
| `misc/` | Empty or scratch folders, ad-hoc SQL |
| `server-dev/` | Old server startup/test scripts |
| `server/` | Retired RAG route experiments under `legacy-routes/` |
| `assets/` | Duplicate images not used by the app |

To restore a file, move it back to the path documented in `REPO_LAYOUT.md` or update the consuming script.
